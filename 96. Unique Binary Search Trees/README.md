<h2>
  <a href="https://leetcode.com/problems/unique-binary-search-trees/">
    Unique Binary Search Trees
  </a>
</h2>

<img src="https://img.shields.io/badge/Difficulty-Medium-yellow" alt="Difficulty: Medium" />

<hr>

<p>
Given an integer <code>n</code>, return the number of structurally unique <strong>BST's</strong> (binary search trees) which has exactly <code>n</code> nodes of unique values from <code>1</code> to <code>n</code>.
</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> n = 3
<strong>Output:</strong> 5
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> n = 1
<strong>Output:</strong> 1
</pre>

<p><strong>Constraints:</strong></p>

<ul>
  <li><code>1 &lt;= n &lt;= 19</code></li>
</ul>
