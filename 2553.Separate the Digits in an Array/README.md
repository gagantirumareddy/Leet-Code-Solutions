<h2>
  <a href="https://leetcode.com/problems/separate-the-digits-in-an-array/">
    Separate the Digits in an Array
  </a>
</h2>

<img src="https://img.shields.io/badge/Difficulty-Easy-brightgreen" alt="Difficulty: Easy" />

<hr>

<p>
Given an array of positive integers <code>nums</code>, return an array <code>answer</code> that consists of the digits of each integer in <code>nums</code> after separating them in the same order they appear in <code>nums</code>.
</p>

<p>
To separate the digits of an integer is to get all the digits it has in the same order.
</p>

<p>
For example, for the integer <code>10921</code>, the separation of its digits is <code>[1,0,9,2,1]</code>.
</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> nums = [13,25,83,77]
<strong>Output:</strong> [1,3,2,5,8,3,7,7]
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> nums = [7,1,3,9]
<strong>Output:</strong> [7,1,3,9]
</pre>

<p><strong>Constraints:</strong></p>

<ul>
  <li><code>1 &lt;= nums.length &lt;= 1000</code></li>
  <li><code>1 &lt;= nums[i] &lt;= 10<sup>5</sup></code></li>
</ul>
