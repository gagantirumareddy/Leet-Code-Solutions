<h2>
  <a href="https://leetcode.com/problems/sequential-digits/">
    Sequential Digits
  </a>
</h2>

<img src="https://img.shields.io/badge/Difficulty-Medium-yellow" alt="Difficulty: Medium" />

<hr>

<p>
An integer has <strong>sequential digits</strong> if and only if each digit in the number is one more than the previous digit.
</p>

<p>
Return a <strong>sorted list</strong> of all the integers in the range <code>[low, high]</code> inclusive that have sequential digits.
</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> low = 100, high = 300
<strong>Output:</strong> [123,234]
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> low = 1000, high = 13000
<strong>Output:</strong> [1234,2345,3456,4567,5678,6789,12345]
</pre>

<p><strong>Constraints:</strong></p>

<ul>
  <li><code>10 &lt;= low &lt;= high &lt;= 10<sup>9</sup></code></li>
</ul>
